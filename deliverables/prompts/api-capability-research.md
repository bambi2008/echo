### Vision (多模态)

| 能力 | 支持 | 产品使用 | 备注 |
|------|------|---------|------|
| 图片理解 | ✅ | 名片扫描、保单 OCR | 通过 `image_url` 传入 base64 |
| 支持格式 | JPEG, PNG, WebP | ✅ | GIF 不支持 |
| 最大图片 | 20MB | ✅ | 名片/文档远小于此 |

### 定价

| 模型 | 输入 / 1M tokens | 输出 / 1M tokens |
|------|-----------------|-----------------|
| deepseek-chat | ¥1 (~$0.14) | ¥2 (~$0.28) |
| Vision 附加 | 按图片分辨率计 | — |

**Echo 典型调用成本：**
- 开场白：~200 input + 50 output = $0.00004/次
- 名片 OCR：~100 input（图片）+ 100 output = ~$0.0001/次
- 销售教练：~500 input + 200 output = $0.00015/次

日均 5 次开场白 + 0.3 次 OCR + 0.7 次教练 = ~$0.0005/天 = ~$0.015/月

**实际成本会被 prompt 长度和重试放大，估计 $0.30/月/用户。**

## 建议

1. **名片 OCR 是第一优先级测试项** — 这是 B2B 的核心差异化功能。用 10 张真实名片（中英文各半）实测 DeepSeek Vision 的提取准确率
2. **火山引擎 ASR 中英混合** — 美国销售的对话中常夹带中文名字，实测混合场景
3. **Fallback 策略** — 当 DeepSeek 不可用时，开场白回退到模板；当火山引擎不可用时，语音备注降级为本地录音（用户手动播放）
4. **成本缓冲** — 预算按 $0.53/月 × 2 = $1/月做成本缓冲，覆盖重试和峰值用量
